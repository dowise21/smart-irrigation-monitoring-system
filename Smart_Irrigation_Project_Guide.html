1. Smart Irrigation Monitoring System

Website quản lý cây/chậu và theo dõi hoạt động tưới tiêu tự động, được xây dựng theo kiến trúc MVC cổ điển với Java Servlet + JSP + JDBC, lưu trữ trên Microsoft SQL Server.

Quản lý vườn & chậu

Thiết lập danh mục cây, định nghĩa ngưỡng độ ẩm lý tưởng và quản lý chậu theo vị trí (ban công, sân vườn).

Giám sát & Lịch tưới

Thu thập độ ẩm đất thời gian thực, lập lịch tự động, lưu nhật ký phiên và tổng hợp hao phí nước.

Cảnh báo & Dự đoán

Bộ lọc cảnh báo ngập úng, rò rỉ, lỗi cảm biến kèm công thức heuristic dự đoán thời điểm đất khô.

Phạm vi mã nguồn thực tế

Project sở hữu giao diện quản trị đầy đủ, các Servlet điều phối, DAO thao tác trực tiếp với SQL Server qua JDBC, và các service tính toán. Một số thành phần IoT phần cứng ở mức mô phỏng REST endpoint.

Lời khuyên bảo vệ đồ án: Giới thiệu đây là Hệ thống Prototype Quản lý & Giám sát Tưới Thông minh. Chỉ khẳng định phần cứng ESP32 và máy bơm tự động nếu nhóm có board vật lý demo kèm theo.

4. Chuẩn bị môi trường

Các bước chuẩn bị môi trường chạy ứng dụng trên máy phát triển.

  1. Cài đặt JDK tương thích (khuyến nghị JDK 8 hoặc JDK 11 cấu hình target 1.8) trên NetBeans.
  2. Cài đặt và cấu hình Server Apache Tomcat (bản 8.5 hoặc 9.0) trong NetBeans Server Manager.
  3. Cài đặt SQL Server, kích hoạt giao thức TCP/IP trên cổng 1433 trong SQL Server Configuration Manager.
  4. Mở NetBeans: File → Open Project và chọn thư mục chứa build.xml.
  5. Kiểm tra các file thư viện trong thư mục Libraries (Driver JDBC mssql-jdbc và JSTL core).
  6. Tạo CSDL SmartIrrigationDB, cấu hình mật khẩu trong DBContext.java và chạy test.

5. Cấu hình kết nối SQL Server

Cách thiết lập kết nối JDBC trong lớp tiện ích DBContext.java.

// src/java/util/DBContext.java
public class DBContext {
    private final String SERVER_NAME = "localhost";
    private final String DB_NAME     = "SmartIrrigationDB";
    private final String PORT_NUMBER = "1433";
    private final String USER_ID     = "sa";        // Điều chỉnh tài khoản của bạn
    private final String PASSWORD    = "your_pass";  // Mật khẩu SQL Server

    public Connection getConnection() throws Exception {
        String url = "jdbc:sqlserver://" + SERVER_NAME + ":" + PORT_NUMBER 
                   + ";databaseName=" + DB_NAME + ";encrypt=true;trustServerCertificate=true";
        Class.forName("com.microsoft.sqlserver.jdbc.SQLServerDriver");
        return DriverManager.getConnection(url, USER_ID, PASSWORD);
    }
}
Bảo mật: Tài khoản SA hiện hardcode trong mã nguồn. Khi đưa lên GitHub hoặc môi trường công khai, cần thay thế bằng biến môi trường (Environment Variable) để tránh lộ credential.

8. Đăng nhập và phiên làm việc (Session)

Luồng xác thực người dùng và cơ chế bảo vệ phiên qua AuthFilter.

  1. Truy cập /login; LoginServlet.doGet() chuyển tiếp đến login.jsp.
  2. Người dùng nhập username và password, gửi POST về /login.
  3. UserDAO.findByUsername() tìm thông tin trong bảng AppUser và lấy tên vai trò từ AppRole.
  4. Hệ thống kiểm tra cờ khóa tài khoản (is_active) và dùng PasswordUtil.verify() so khớp mật khẩu.
  5. Nếu hợp lệ, đối tượng User được lưu vào session.setAttribute("LOGIN_USER", user) và chuyển hướng đến /dashboard.
Cảnh báo API thiết bị: AuthFilter hiện áp dụng cho /* trừ /login và static files. Các endpoint IoT như POST /sensor-data khi phần cứng gọi không có Cookie Session sẽ bị đá về màn hình đăng nhập. Cần bổ sung token-based whitelist cho IoT.

16. Dự đoán thời điểm đất khô

Thuật toán ước tính số giờ còn lại trước khi đất đạt trạng thái cần tưới.

// src/java/service/MLService.java
double baseDryHours   = 12.0;
double moistureFactor = currentMoisture * 0.2;
double waterFactor    = (recentWaterMl / 100.0) * 0.5;
double lightFactor    = (lightLux / 1000.0) * 1.5;

double totalHoursToDry = baseDryHours + moistureFactor + waterFactor - lightFactor;
if (totalHoursToDry < 1.0) totalHoursToDry = 1.0;

// Confidence hiện được sinh ngẫu nhiên 75% - 95%
Lưu ý học thuật: Công thức trên là một mô hình Heuristic tuyến tính có tính toán ánh sáng và độ ẩm, chưa phải là Model Machine Learning (như Random Forest hay LSTM) huấn luyện trên dataset thật. Hãy trình bày trung thực trước hội đồng.

19. Vai trò của Model, DAO & Service

Cách phân tách các tầng kiến trúc trong mã nguồn.

1. Model (POJO)

Chứa các trường dữ liệu getter/setter tương ứng với bảng DB: Plant, Pot, SensorData, WateringSchedule, Alert, AppUser.

2. DAO (Database Access)

Mở kết nối JDBC, chuẩn bị câu lệnh PreparedStatement, mapping ResultSet sang Model và đóng kết nối an toàn.

3. Service Layer

Chứa các giải thuật nghiệp vụ độc lập như AlertService (luật cảnh báo) và MLService (ước lượng đất khô).

  2. 0:30 - 1:00 (Đăng nhập): Đăng nhập với tài khoản Admin, trình bày cơ chế mã hóa mật khẩu và phân quyền với AuthFilter.
  3. 1:00 - 2:00 (Quản lý vườn & chậu): Thao tác thêm một cây mới với ngưỡng ẩm lý tưởng, sau đó gán vào chậu ở khu vực cụ thể.
  4. 2:00 - 3:00 (Giám sát cảm biến): Trình diễn bảng theo dõi độ ẩm thời gian thực của chậu và thao tác gửi dữ liệu thử nghiệm.

  7. 5:00 - 5:30 (Tổng kết & Hướng phát triển): Xuất báo cáo CSV, nêu trung thực các điểm đang ở mức prototype và kế hoạch kết nối mạch ESP32 thực tế.
