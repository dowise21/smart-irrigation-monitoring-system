1. Smart Irrigation Monitoring System

Nền tảng Quản trị & Giám sát Tưới tiêu Tự động ứng dụng IoT dành cho đồ án môn PRJ301 (Fall 2026), phát triển theo kiến trúc MVC2 nghiêm ngặt trên nền Java Servlet + JSP + JDBC và Microsoft SQL Server.

Quản lý Vườn & Khu vực

Giám sát IoT & Chỉ số Nước

4. Chuẩn bị môi trường & Triển khai

Quy trình thiết lập môi trường phát triển và kiểm tra tính tương thích trên máy trắng.

  1. Cài đặt JDK: Cài đặt JDK 1.8 hoặc JDK 11 (cấu hình Source/Binary Format = 1.8 trong NetBeans).
  2. Cài đặt Web Server: Tải Apache Tomcat 9.0 (hoặc 8.5), thêm vào NetBeans qua Tools → Servers → Add Server.
  3. Bật TCP/IP SQL Server: Mở SQL Server Configuration Manager → SQL Server Network Configuration → Protocols for MSSQLSERVER → Chọn TCP/IP = Enabled, kiểm tra Port 1433. Khởi động lại service SQL Server.
  4. Mở dự án trong NetBeans: Chọn File → Open Project, trỏ đến thư mục chứa build.xml.
  5. Khởi tạo CSDL: Chạy lần lượt 3 tệp SQL trong thư mục sql/ vào SQL Server Management Studio (SSMS).
  6. Cấu hình mật khẩu SA: Mở tệp src/java/util/DBContext.java, điền mật khẩu tài khoản SQL Server của máy bạn.
  7. Biên dịch & Chạy: Chuột phải vào Project → Chọn Clean and Build → Chọn Run.

5. Cấu hình CSDL & Bộ 3 Tệp SQL Chuẩn

Kết nối JDBC được quản lý tập trung và CSDL được tách thành 3 tệp SQL riêng biệt theo đúng rubric chấm thi.

// src/java/util/DBContext.java
package util;

import java.sql.Connection;
import java.sql.DriverManager;

public class DBContext {
    private static final String SERVER_NAME = "localhost";
    private static final String DB_NAME     = "SmartIrrigationDB";
    private static final String PORT_NUMBER = "1433";
    private static final String USER_ID     = "sa";        // Điều chỉnh tài khoản SQL
    private static final String PASSWORD    = "123456";    // Mật khẩu SQL của máy bạn

    public static Connection getConnection() throws Exception {
        String url = "jdbc:sqlserver://" + SERVER_NAME + ":" + PORT_NUMBER 
                   + ";databaseName=" + DB_NAME 
                   + ";encrypt=true;trustServerCertificate=true";
        Class.forName("com.microsoft.sqlserver.jdbc.SQLServerDriver");
        return DriverManager.getConnection(url, USER_ID, PASSWORD);
    }
}

9. Dashboard & Phân tích Chỉ số Nước

Bảng điều khiển trung tâm hiển thị các chỉ số KPI lượng nước tưới tiêu theo thời gian thực và biểu đồ phân tích xu hướng giữ nước của đất.

Water Delivered (Nước đã cấp)

SUM(water_ml) / 1000.0 (Lít)
Tổng lượng nước hệ thống đã bơm vào tất cả các chậu cây.

Water Retained (Nước giữ lại)

SUM(water_ml * retain_ratio) / 1000.0 (Lít)
Lượng nước đất thực tế hấp thụ thành công phục vụ rễ cây.

Water Waste (Nước hao phí)

Nước đã cấp - Nước giữ lại (Lít)
Lượng nước bị rò rỉ, bốc hơi nhanh hoặc chảy tràn ra đáy chậu.

Active Alerts (Cảnh báo mở)

COUNT(*) WHERE is_resolved = 0
Số lượng sự cố úng rễ, rò rỉ hoặc lỗi cảm biến đang chờ xử lý.

Biểu đồ nội bộ: Biểu đồ được xây dựng bằng Chart.js kết hợp canvas vẽ trực tiếp, tính toán số liệu từ bảng WaterAnalysis theo từng ngày, bảo đảm không bị lỗi khi phòng chấm thi không có kết nối Internet.

15. Động cơ Cảnh báo Sự cố (Alert Rules Engine)

5 quy tắc cốt lõi được cài đặt trong AlertService.java và được gọi tự động từ luồng tưới (WateringSessionDAO, IrrigationHistoryDAO) và luồng telemetry (SensorDataDAO.insert → evaluateIncomingTelemetry).

Math Engine (công thức chuẩn)

Đại lượngCông thứcHàm
Retain Ratio(weight_after - weight_before) / water_ml (đổi kg → ml khi cần, kẹp trong 0..1)calculateRetainRatio
Water Wastewater_ml - (retain_ratio * water_ml)calculateWaterWaste
Dry Ratedelta_weight / delta_time (kg/giờ)calculateDryRate

5 quy tắc cảnh báo

16. Dự đoán Thời điểm Đất Khô (Soil Drying Forecast)

Mô hình tính toán thời gian đất bốc hơi hết nước dựa trên các đặc trưng độ ẩm hiện tại, lượng nước đã tưới gần nhất và cường độ ánh sáng.

// src/java/service/MLService.java
double baseDryHours   = 12.0;
double moistureFactor = currentMoisture * 0.2;            // Đất càng ẩm -> giữ nước lâu hơn
double waterFactor    = (recentWaterMl / 100.0) * 0.5;    // Đã tưới nhiều -> lâu khô hơn
double lightFactor    = (lightLux / 1000.0) * 1.5;        // Nắng gắt (Lux cao) -> bốc hơi nhanh hơn

double totalHoursToDry = baseDryHours + moistureFactor + waterFactor - lightFactor;
if (totalHoursToDry < 1.0) totalHoursToDry = 1.0;

// Độ tin cậy (Confidence Score) tính dựa trên độ lệch các cảm biến
Bảo vệ đồ án trung thực: Trình bày rõ trước hội đồng đây là Mô hình Heuristic hồi quy tuyến tính thực nghiệm có cân nhắc ánh sáng môi trường, làm tiền đề cho việc huấn luyện mô hình Machine Learning thực tế sau này.

19. Thiết kế Tầng Model, DAO & Service

Phân chia trách nhiệm rõ ràng theo nguyên tắc thiết kế Separation of Concerns trong kiến trúc hướng đối tượng.

1. Model (Data Transfer Objects)

Các đối tượng POJO thuần túy đại diện cho bảng dữ liệu: AppUser, Plant, Pot, SensorData, WateringSchedule, Alert... Đảm bảo đóng gói dữ liệu an toàn với getter/setter.

2. Data Access Object (DAO)

Độc quyền mở và đóng kết nối JDBC qua DBContext. 100% sử dụng PreparedStatement để truyền tham số an toàn, tách biệt hoàn toàn câu lệnh SQL khỏi logic giao diện.

3. Service Layer

Xử lý tính toán nghiệp vụ độc lập: AlertService tính tỷ lệ giữ nước và phát hiện rò rỉ; MLService tính toán thời gian đất khô. Dễ dàng viết Unit Test độc lập.
